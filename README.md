# 🛒 NestJS E-Commerce Backend API

A scalable and production-ready E-Commerce Backend API built with **NestJS**, **TypeScript**, and **MongoDB** following a modular architecture and backend best practices.

This project provides secure authentication, product management, shopping cart, coupon system, order management, Stripe payment integration, caching with Redis, and real-time communication using WebSockets.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/os2488965-crypto/nestjs-ecommerce-api.git
```

Go to project

```bash
cd nestjs-ecommerce-api
```

Install dependencies

```bash
npm install
```

Create environment file

```bash
cp .env.example .env
```

Run development server

```bash
npm run start:dev
```

Build project

```bash
npm run build
```

Production

```bash
npm run start:prod
```
